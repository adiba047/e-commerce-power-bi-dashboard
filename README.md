this project contains an e-commerce sales dashboard using power bi showing count of customers , revenue generated , revenue-loss , AOV , cancellation rate revenue generated by category , state , product ,etc. 
This project includes slicers , KPI cards , bar charts , line chart .
data cleaning and transforming - using power query
data modeling - building relationship 
building KPI - using DAX formulas , measures , columns 
data visualization - using different charts , slicers , cards
